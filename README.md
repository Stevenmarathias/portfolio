# Steven Marathias · Analytics Portfolio

Personal portfolio built with Next.js 15 and React 19.

## Run locally

```
npm install
npm run dev
```

Then open http://localhost:3000.

## Edit content

- Featured projects, About, Résumé and Contact: `app/page.tsx`
- Coursework strip: `lib/coursework.ts`
- Styles and colors: `app/globals.css`
- Headshot and résumé PDF: `public/`

## Deploy

Import this repo at vercel.com/new. Vercel detects Next.js automatically; no settings needed.
